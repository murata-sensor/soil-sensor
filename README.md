# Murata Soil Sensor
Developer resources, sample code, and tools for evaluating and integrating Murata soil sensors.

This repository serves as an index of software resources provided by Murata Manufacturing Co., Ltd. for evaluating and integrating Murata soil sensors.

> [日本語版はこちら](#日本語)

---

## English

### Overview

Murata soil sensors are designed to measure soil conditions including:

* Electrical conductivity (EC)
* Volumetric water content (VWC)
* Temperature

This page provides links to sample code, tools, and other software resources that can help you evaluate Murata soil sensors and integrate them into your system.

### Sample Code

| Repository                                                                                | Description                                                                                                                                                                                                                        |
| ----------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| [soil-sensor-samples-python](https://github.com/murata-sensor/soil-sensor-samples-python) | Python sample code for communicating with Murata soil sensors from Windows, Linux, macOS, and Raspberry Pi. It includes examples for reading measurements and sensor information, continuous logging, and other common operations. |

Additional sample code and supported platforms may be added in the future.

### Applications and Tools

| Repository                                                                                  | Description                                                                                                                            |
| ------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------- |
| [soil-sensor-data-monitoring](https://github.com/murata-sensor/soil-sensor-data-monitoring) | Example system for collecting and visualizing soil sensor and environmental logger data using Google Sheets and a web-based dashboard. |

## 日本語

### 概要

村田製作所の土壌センサは、土壌の以下の状態を測定するためのセンサです。

* EC（電気伝導度）
* 体積含水率（VWC）
* 温度

このページでは、村田製作所の土壌センサの評価や、お客様のシステムへの組み込みにご利用いただけるサンプルコード、ツールなどのソフトウェア関連情報をご案内します。
